# v0.12.0 — Release record

Status: released as v0.12.0 on 2026-11-13 from `6667911`
(<https://github.com/Matrix-I/litty-terminal/releases/tag/v0.12.0>), built
and signed by the tag-triggered workflow. `6667911` is the validated
`c28f466` plus a test-only fix: the first tag run failed on the macos-15
runner because the bundle install test re-signed a copy of `/bin/echo`
(arm64e), which macOS 15 refuses to run; the test now builds an arm64
fixture. The tag was moved to `6667911` before any release was drafted.
A MINOR release: Linux
Vulkan robustness and X11 integration (IME, monitors, theme, fullscreen,
`WM_CLASS`, UTF-8 titles), the security and robustness fixes carried over
from the v0.11.0 source review, a byte-budget scrollback default, and the
last two findings of the 2026-11-10 performance review.

Validation: [archived pre-release report](../validation/release-0.12.0.md).
The Linux fixes were checked on real Linux hardware by the maintainer
(2026-11-13), on top of the container and Intel UHD 620 runs recorded in
`ROADMAP.md` and plans [B](./2026-11-11-review-fixes-b-vulkan-robustness.md)
and [C](./2026-11-11-review-fixes-c-vulkan-images.md).

## Shipped

### Behavior change

- Scrollback defaults to a 10,000,000-byte budget instead of 5,000 lines:
  about 10,400 lines at 80 columns and 4,166 at 200 columns. The key and
  its unit are unchanged (`94331c7`).

### Security

- The signed `SHA256SUMS.txt` names its release tag
  (`# litty-release: vX.Y.Z`) and the updater rejects a manifest without
  the matching tag, so an old signed manifest cannot be replayed for a
  newer release. Older builds ignore the comment line and still update
  (`d1eaea2`).
- macOS updates stage the full bundle and swap it in atomically
  (`d1eaea2`).
- Kitty `t=f`/`t=t` failures all reply `EPERM`, so replies no longer
  reveal whether a file exists (`d1eaea2`).

### Fixes

- Paste outside bracketed mode turns CRLF and LF into CR (`d1eaea2`).
- A failed shell spawn no longer blocks the PTY reader for two seconds
  (`d1eaea2`).
- Clipboard copies and history deletions are bounded queues that report
  overload; history reloads run in the background (`d1eaea2`).
- Kitty graphics: unsupported `a=d` selectors are rejected without
  touching images, `I=` replies carry the assigned id, APNGs fall back to
  the default image, animation loop lengths saturate (`d1eaea2`,
  `007cd20`).
- History: removing a command deletes every occurrence; fish history is
  unescaped in one pass (`6a8c7fe`, `82fde6f`).
- AI: transport failures that cannot succeed are no longer retried; the
  system prompt stays cacheable (`90c1d7e`, `d1eaea2`).
- macOS: covered, minimized or hidden windows stop drawing and shrink
  their drawables (`dc766fa`).

### Linux

- X11 input methods (XIM, on-the-spot preedit), dead keys and Compose;
  the real monitor under the window (RandR); light/dark theme from the
  XDG settings portal; fullscreen through the window manager (`13073b6`).
- `WM_CLASS` is `litty` so launchers show the icon; titles are UTF-8
  `_NET_WM_NAME` (`91de8c7`, `c3163c3`).
- The requested mouse cursor is shown and hidden while typing; the
  window manager's maximize state is followed; resizes keep the last
  frame instead of flashing black (`23ba626`, `e30ab0f`, `7652831`,
  `df8bd3f`).
- Vulkan: closed windows release their swapchain and surface; each
  swapchain image has its own semaphore; windows wait for each other's
  frames before reusing shared state; every creation, submit and present
  result is checked; the device is picked by present and shader support;
  inline images bind their own texture and upload from the right layout;
  render-target textures get real framebuffers; `custom-shader` is
  reported unsupported once per process (`2850eef`, `2bae9fd`,
  `a3cf8bb`, `648f717`, `7d1e1f4`, `9d62755`, `b616504`, `46676f6`,
  `a3c42f6` and others).
- `bundle_linux.sh` builds a local binary, `.deb` and `.rpm` in one
  command (`43152e2`).

### Performance

- Alternate-screen full-screen scrolls rotate a ring instead of copying
  rows: `alt_scroll` 28.0 → 1.10 ns/byte (`ab6f72a`).
- Runs of narrow non-ASCII text are written in batches: `vietnamese`
  9.0 → 3.4 ns/byte (`4a94cad`).
- Background tabs resize once a resize burst settles (`7f3800a`); atlas
  slot keys hash with one multiply (`2e77e55`).
- Linux: texture uploads join the frame's submission and small uploads
  reuse one staging buffer: 1024 new glyphs 131 → 8 ms on an Intel
  UHD 620 (`2097c91`, `81ae3e0`).
