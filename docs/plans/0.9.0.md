# v0.9.0 — Release record

Status: released as v0.9.0 on 2026-11-05 (release notes:
<https://github.com/Matrix-I/litty-terminal/releases/tag/v0.9.0>). It ships the
[v0.8.1](./0.8.1.md) fix plan (never tagged) together with the tab drag-and-drop
work and the Linux seamless title bar. The version is MINOR because new features
landed after v0.8.0.

Validation: [archived pre-release report](../validation/release-0.9.0.md).
