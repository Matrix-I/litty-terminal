# v0.11.1 — Release record

Status: prepared for release (not yet tagged). A PATCH release with the
fixes from the [v0.11.0 source review](../validation/2026-11-10-source-review.md),
two OSC 8 file-link hardening fixes, the first two findings of the
parser and grid performance review, and macOS window fixes.

Centering new windows (`eadfda8`, committed as `feat`) ships in this PATCH
release by decision of the maintainer: it fixes first windows opening in
the top-left corner and adds no config key or keybinding.

Validation: [archived pre-release report](../validation/release-0.11.1.md).

## Shipped

### Security

- OSC 8 `file://` links naming another host are no longer clickable
  (CWE-610, `bc66974`).
- Cmd/Ctrl+Click opens only non-executable files with a viewer/editor
  extension and directories; everything else is revealed in the file
  manager instead (CWE-829, `e23b043`).

### Fixes

- Click-to-move no longer panics (and aborts every window) when the input
  mark sits past the last non-blank cell (`61511fb`).
- `ESC c` (RIS) resets the scrollback length (`d37a085`).
- OSC 0/2 window titles keep their semicolons (`a0f7ebc`).
- Vertical cursor moves stay inside scroll margins; the cursor report no
  longer underflows in origin mode (`cd91c8c`).
- After a burst of resizes, the pane's foreground process gets SIGWINCH
  once more, so vim no longer stays drawn at a stale size (`86967b8`).
- macOS: a live window drag-resize redraws instead of freezing until the
  mouse is released (`5de0230`).
- macOS: holding Cmd across Cmd+N / Cmd+W repeats the shortcut instead of
  typing `n` / `w` (`442534c`).
- macOS: cascaded Cmd+N windows no longer run off screen on 2x displays
  (`f41eaa6`).
- macOS: new windows open centered on the focused screen (`eadfda8`).

### Performance

- OSC 8 links are interned by hash without allocating: `osc8_links`
  32.0 → 17.7 ns/byte, `osc8_ls` 21.6 → 12.4 ns/byte (`f210d47`).
- A resize that only changes the row count skips the scrollback reflow:
  1.77 ms → 0.0035 ms at 160 columns, 5000 lines (`15bca71`).

## Carried over

- [Performance review](../validation/2026-11-10-perf-review.md) findings 3
  (O(rows × cols) alt-screen scroll) and 4.
- Source review lower-severity items other than OSC 8 `file://` links:
  paste LF handling, update signature not binding the version, non-atomic
  macOS bundle update, `spawn_reader` failure delay, dropped clipboard
  copies, Kitty `t=f` existence oracle, misplaced `paste.rs` doc comment.
- Linux: new windows are not centered yet.
