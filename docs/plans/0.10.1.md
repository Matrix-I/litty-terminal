# v0.10.1 — Release record

Status: prepared (`v0.10.1` not yet tagged). `v0.10.1-rc.1` (`2d2bbe9`)
failed in the macOS bundle step: `macos-15` has `diskutil image create from`
without `--volumeName`; `bundle_macos.sh` now probes for the option and falls
back to `hdiutil`, and `v0.10.1-rc.2` retests the workflow. A PATCH hotfix for two macOS window
regressions and one macOS keyboard regression in v0.10.0. It is also the first
release built by the tag-triggered workflow (`.github/workflows/release.yml`).

Validation: [archived pre-release report](../validation/release-0.10.1.md).

## Shipped

- Pointer no longer stays hidden after Cmd+W / Cmd+N with
  mouse-hide-while-typing on (`a22acbc`).
- Closing the key window hands key to the frontmost remaining window on the
  active Space, so Cmd+W and typing keep working without a click (`9768a8f`).
- Arrows, F-keys, Home/End, PageUp/Down and Forward Delete send their proper
  sequences under the Kitty keyboard protocol instead of AppKit Private Use
  text (`48357a6`); arrows work again in pickers such as Claude Code's.

## Scope note

Released from `main` instead of a branch cut from `v0.10.0`: `main` holds only
these three fixes plus the release workflow and docs since that tag, and the
workflow must be in the tagged commit for the tag to trigger it.
