Status: prepared 2026-11-21; not yet tagged. A PATCH release from `main`,
which since [v0.14.0](./0.14.0.md) holds only the five fixes below (no config

Validation: [release-0.14.1](../validation/release-0.14.1.md).

## Shipped

### Fixes

- `background-opacity` takes effect on X11: windows that ask for
  transparency use a 32-bit TrueColor visual (`4a16c67`).
- `background-opacity` is no longer exceeded on default-background cells
  (0.5 rendered as 0.75) on Vulkan and Metal (`19738f5`).
- Translucent frames are presented premultiplied where the compositor
  expects it (X11 `PRE_MULTIPLIED`, macOS non-opaque layer), so translucent
  colors are no longer too bright (`42320d7`).
- macOS: `cursor-style-blink = true` blinks again (`66055e7`).
- With a single tab and no title bar band (macOS), the first terminal row
  takes clicks again instead of selecting or closing the tab (`c0ef120`).
