# v0.11.0 — Release record

Status: released as v0.11.0 on 2026-11-09 from `70c6aa9`
(<https://github.com/Matrix-I/litty-terminal/releases/tag/v0.11.0>), built
and signed by the tag-triggered workflow. A MINOR release
that ships the [performance gap plan](./2026-11-08-performance-gaps.md): new
end-to-end benchmarks, throughput, startup and memory fixes, and the measured
numbers now published in `README.md` and `docs/development/performance.md`.

Validation: [archived pre-release report](../validation/release-0.11.0.md).

## Shipped

### Benchmarks (new CLI commands)

- `+bench-input-latency`: synthetic key → GPU-completed frame with the echo
  (`1bca032`).
- `+bench-first-frame`: process spawn → GPU-completed first frame
  (`ebfc8da`).
- `+bench-pty-throughput`: bytes through the whole app next to a parser-only
  rate (`399a777`); waits bounded in `b6f322e`.

### Performance

- Shaped runs are cached instead of reshaped every frame (`8ee494f`), and the
  sized CTFont is no longer recreated per glyph (`964fa09`): `code` stream
  58.5 → 150.9 MB/s, `sgr` 119 → 152 MB/s in app.
- Fonts load and Metal shaders compile during launch, overlapped
  (`5181cdc`, `f6d60f2`).
- OSC 8 links: the extras scan is skipped when every slot is provably in use
  (`d1bba4c`): 4.8 → 26.5 MB/s in app.
- UTF-8 characters are batched in the `feed_bytes` fast path (`4872e8e`):
  Unicode 52.6 → 77.2 MB/s in app.
- The terminal reply buffer is reused for short replies (`7a48f81`).
- The color glyph atlas is created on first use (`b2c3b8e`).

### Fixes

- Font lock-order cycle in `set_font_features` (`27f0939`).
- macOS: the unbundled Dock icon is set once per process and not in
  benchmarks; each new window no longer decodes it again (`6264c9b`).
- macOS: a closed window's drawable is freed when no window is left
  (`79d44ef`): 0-window footprint 47–48 → 32–33 MB at the time of the fix.

## Carried over

- T1 (shaping/rasterization under the grid lock): deferred, ≤ 3% of lock
  time after T2.
- T5 leftover: emoji cluster interning (SipHash kept on purpose).
- The macOS `winit` vs native benchmark from `0.10.0.md` §2 (informational;
  `winit` is already removed).
